## 二、项目一句话

Strata 是「小方工作室」自研的 **Windows 优先、全中文、永久免费开源（MIT）的 Photoshop 平替**，修图与绘画并列为一级能力，交付形态是一个 `Strata.exe`。

| 维度 | 结论 |
|------|------|
| 是什么 | 平替 PS 的桌面修图 / 合成 / 绘画工具，覆盖「图层－蒙版－调整－后期」完整工作流 |
| 给谁 | 中文用户、Windows 用户；永久免费、不盈利、无广告、无遥测 |
| 技术栈 | **Tauri v2**（Rust 内核 + 系统 WebView2）+ React + TypeScript + Vite + **WebGPU（回退 WebGL2）** + Rust `rayon` |
| 硬指标 | 安装包 / 绿色版 **≤ 100MB（红线）**，目标 10–20MB |
| 不做什么 | **不含任何 AI / 机器学习功能**；不做 3D / 视频 / 云端 |
| 参考谁 | `D:\Compositor`（macOS 开源项目，MIT）——只参考 UI 组织、功能划分、工程格式与逻辑骨架，**代码一行不抄** |
| 仓库 | `https://github.com/xiaofangstudio/Strata`（本地仓库：`D:\20533\Desktop\Strata`） |

> **一句话记住**：`要做就做完整版，不做玩具；修图与绘画并列一级；体积守 100MB 红线；不含 AI；中文第一、Windows 第一、开源免费。`

## 三、铁律（已经锁定，不要擅自改）

1. **平台与协议**：Windows 优先、全中文（无英文硬编码残留）、MIT 协议、永久免费不盈利。
2. **从零自研**：不复制 `D:\Compositor` 的任何代码，只借鉴思路；不复制任何开源项目代码。
3. **能力并列**：修图与绘画同为 Level-1，两条线都不打折（详见立项规划书 §1.4）。
4. **无 AI**：不引入 ONNX Runtime、Windows ML、DirectML 或任何模型文件。这是定位的一部分，不是暂缺。
5. **体积红线 ≤ 100MB**：选型即约束，只引入纯 Rust 轻量库；打包超标即视为失败。
6. **交付形态**：桌面 `.exe`，不是浏览器应用；依赖系统 WebView2（安装包引导安装，不计入红线）。

## 四、界面与交互的既定决策（用户明确纠正过，勿回退）

这几条是用户亲自拍板、并纠正过早期错误方向的，接手时**不要"帮忙优化"回去**。

| 项 | 结论 |
|----|------|
| 左侧工具栏 | **保留 30+ 工具直接可见，不做分组折叠**。按钮维持常规尺寸，**不放大图标、不加过大间距**（放大反而"像宝宝玩具"）。靠风格统一 + 形状区分来让人分清 |
| 整体观感 | 不廉价、简约扁平、不显老。Krita 那种"控件全堆台面"的拥挤感要避免；PS 的臃肿也要再改 |
| 面板 | 右侧单列标签（图层 / 通道 / 路径），其余（颜色、调整、历史、笔刷库、属性）改为按需呼出的浮层 |
| 菜单 | 菜单入口保留，另配命令面板 `Ctrl+K` |
| 选项条 | 固定 **3 项随工具变化 + 「⋯ 更多」**，长度恒定 |
| 工作区 | **一套界面，两个工作区**（修图 / 绘画）。切换只改默认工具集与面板露面项，不维护两套界面 |
| 视觉 | 扁平、统一圆角（8 / 12 / 999）、浅色默认 + 深色可切；品牌紫为唯一强调色 |

### 开始页面（M0 的交付核心）

桌面端启动后先进入**开始页面**（与 Figma / Blender / Office 一致），不是直接进编辑界面。

- 区块：**新建画布** / **最近文件** / **导入** / **其它入口**（示例工程、快捷键速览、主题切换、关于）。
- 行为：首次启动无历史时显示空状态引导；顶部保留应用标识与主菜单；**关闭全部文档回到开始页面，程序不退出**。
- 交付归属：开始页面属于 **M0**；M0 不做正式编辑界面。

Logo 为**深灰圆角方块 + 白色 `St` 字标**，素材已入库到 `assets/brand/`。

## 五、生态位（工作室产品线）

用户的目标不是做一款软件，而是做**一整套工具生态链**。当前只做 Strata，其余已登记在案、暂不动工。

| 位次 | 产品 | 定位 | 状态 |
|------|------|------|------|
| ① | **Strata** | 修图 / 绘画 | **进行中 · 当前唯一焦点** |
| ② | 剪辑软件（代号待定） | 视频剪辑 + 节点合成，方向为整合 Clypra 与 Gaffer | 预定 · 以后做 |
| ③ | **FangKit** | 三款产品共享的原生底座与界面组件库 | 预定 · 第二个产品前从 Strata 抽取 |

两条边界要守住：Strata 未达可用版本前，不启动剪辑软件的任何工程动作；Strata 开发中保持可复用边界，但**不提前把未定型接口固化成包袱**。完整规划见 `生态规划.md`。

背景要点：**Clypra**（Tauri 2 + React + TS + FFmpeg，MIT）与 Strata **同栈**，是可复用底座的天然一块；**Gaffer**（C++ / Python / OSL，BSD-3-Clause）是节点式 VFX 应用，与 Tauri + Web 前端是两个世界，**只能借鉴节点图与合成管线的思路在自家栈内重写，不能直接拼装**。

## 八、下一步（M0 · 骨架）

M0 的目标是**能启动的入口**，验收标准是「双击即开、从开始页进图，安装包 < 100MB（目标 < 20MB）」。

1. **确认推送**：把本地领先远端的提交推到 `origin/main`（提交后先 `git status -sb` 确认）。
2. **装工具链**：安装 Rust（rustup）+ `create-tauri-app`；确认 `cargo` / `rustc` 可用。
3. **初始化工程**：用 `create-tauri-app` 生成 Tauri v2 + React + TypeScript + Vite 骨架，落到仓库根。
4. **落地开始页面**：按 §四 的区块与行为实现开始页面；启动即进开始页。
5. **最小画布闭环**：打开图片 → 显示 → 导出 PNG（先打通链路，不做正式编辑界面）。
6. **体积门禁**：M0 就打一次包，确认安装包 < 100MB，把体积校验尽早立起来。
7. **品牌图标**：从 `assets/brand/` 的 Logo 裁掉浅蓝底，生成 Tauri 图标集放入 `src-tauri/icons/`。

之后按 M1 → M2 → M3 逐层加厚（P0 / P1+P2 / P3），详见立项规划书 §十。

## 九、环境与已知坑

| 坑 | 现象 | 处理 |
|----|------|------|
| rustup 未安装 | 无法执行 `cargo` / `create-tauri-app` | M0 第一步先装 |
| hosts 文件污染 | `api.github.com` 解析失败 | 用 `curl.exe --resolve` 指定 IP 绕开 |
| GitHub release CDN 重置连接 | 大文件下载中断 | 走镜像，或 `curl.exe --http1.1 -C -` 断点续传 |
| PowerShell 下 `git push` 报 NativeCommandError | 推送其实成功，但被当作错误 | 先设 `$ErrorActionPreference='Continue'` 再 push |
| `D:\20533\Desktop\API\` 有明文 GitHub token | 泄露风险 | **绝不允许提交进任何仓库**；该 token 应予撤销 |
| `.gitignore` 未排除 `assets/` | Logo 会正常入库 | 这是有意的，约 160KB，可接受 |

## 十、协作约定

- **全程中文**：所有对话、文档、界面文案一律简体中文。
- **改文档的规矩**：用读—改的方式编辑，同步更新头部版本号、`本版变更` 小节与页脚版本；规划书与生态规划各自独立计版本。
- **表述风格**：直接、务实，不写空洞的"确保/赋能/闭环"；不编造数据或结果；避免"不是 X 而是 Y"式的抒情句式。
- **用户偏好**：讨厌玩具感与臃肿界面；要完整版、要能日常用；README 与文档要能直接看懂。
- **权威顺序**：产品规格冲突时，以 `立项规划书.md` 为准；产品线冲突时，以 `生态规划.md` 为准。
