## 4. 实现要点（零假功能口径）

### 4.1 P0-1 Shift 直线连线（修假功能）
- `EditorShell` 画笔 onDown：若 `shiftKey` 且存在上一次落点（`lastPaintPointRef`，抬笔时记录），则不进入自由笔画，改调 `Stroke` 的两点直线模式：在 `paint.ts` 加 `strokeLineSegment(from, to, settings)`——用同一笔尖沿两点插值盖章（复用间距逻辑），保证与手绘笔刷完全同核。
- 修饰键速查面板的文案保持不变（终于名副其实）。橡皮同样支持。

### 4.2 P0-2 锁定透明像素
- `core/layer.ts` 图层加 `alphaLock?: boolean`（可选字段）。
- 合成落笔：`paint.ts` 抬笔合成时若激活层 `alphaLock`，先取图层 alpha 生成 mask，`destination-in` 裁剪笔画缓冲（与选区裁剪同一路径，paint.ts:1321-1345 旁新增分支）。
- UI：OptionsBar 笔刷段「更多」+ LayersPanel 图层行加锁定透明按钮（棋盘格图标）；i18n 六语言。

### 4.3 P0-3 画布视图旋转（不改像素）
- `EditorShell` 视图状态加 `viewRotation`（0-360，快捷键 R 拖动 / 触控板双指旋转 / 触屏双指）。
- DOM：现有画布容器 transform 已有 scale/translate，追加 `rotate(var(--view-rot))`；`zoomLiveRef` 的 RAF 缓动同时驱动旋转（复用 motion.ts `shortestAngleDelta`）。
- 快捷操作：`Shift+R` 重置 0°；状态栏显示角度可点击归零。导航器同步旋转指示。

### 4.4 P1-4 对称扩展（径向 + 自定义轴心）
- `paint.ts` 对称配置扩展：`mirror`（现有）+ `radial{count, centerX, centerY}`（每笔尖绕轴心旋转 2π/count 落 N 次）+ 轴对称轴心可拖。
- UI：OptionsBar「更多」对称下拉扩为：关/垂直/水平/双轴/径向(2-16)；开启径向或轴对称时画布上显示可拖轴心手柄（复用变换手柄的绘制风格 + motion.css 反馈）。

### 4.5 P1-5 透视辅助线（1/2/3 点）
- 新组件 `ui/components/PerspectiveGuide.tsx`：纯 overlay（SVG 层，同 `.editor-measure` 模式），不参与像素。
- 数据：`prefs` 存 `perspectiveGuides: {mode: "off"|"1pt"|"2pt"|"3pt", points: {x,y}[], opacity}`；1 点=中心+放射线，2/3 点=消失点+网格线。
- 绘画不强制吸附（吸附后置）；显示/隐藏走视图菜单 + 快捷键 `Ctrl+Shift+P`。

### 4.6 P1-6 色环取色器
- `ColorPicker.tsx` 加第三形态 `wheel`：色环（conic-gradient 环 + 中心 SV 三角/方块），与现有 SV 方块并列可切（记住偏好）。
- 悬浮调色盘：ColorPanel 加「浮窗」模式（`position:fixed` 小卡片，可拖动，画笔工具时常驻），从画笔 OptionsBar 色块长按/按钮唤出；拖动用 pointer events，出界回弹。

## 5. UI 排布设计（新增功能放哪、怎么排）

原则：**不新增顶层工具**（工具轨已 6+7 件），全部收进现有容器，避免 UI 膨胀。

| 功能 | 位置 | 形态 |
|---|---|---|
| Shift 直线 | 无 UI | 快捷键行为 + 速查面板已有文案 |
| 锁定透明像素 | ① LayersPanel 图层行图标（锁定组旁）② OptionsBar 笔刷「更多」开关 | 图标按钮，双入口 |
| 视图旋转 | ① 状态栏角度指示（点击归零）② 触控板/触屏双指手势 ③ `R` 按住拖动 | 无新面板 |
| 径向对称 | OptionsBar 笔刷「更多」对称段下拉（关/垂/水/双轴/径向 N） | 下拉 + 画布轴心手柄 |
| 透视辅助线 | 视图菜单 + UtilityPanel「辅助」分组开关 | overlay SVG |
| 色环 | ColorPicker 形态切换（seg control：方块/色环）+ 记忆 | 组件内切换 |
| 悬浮调色盘 | OptionsBar 颜色块旁小按钮唤出 | fixed 浮窗，可拖动 |
| 压感曲线（P1 后续） | BrushSettingsPanel 新 tab「压感」 | 曲线编辑器 |

i18n：新增文案全走 `preferences`/`panel`/`tools` 对应分组，六语言 `Dict` 契约保证不缺键；控件沿用 `pref-row`/`modal-foot` 体系 + `white-space: nowrap` 约定，防溢出。
