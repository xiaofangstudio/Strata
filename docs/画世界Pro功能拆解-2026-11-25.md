## 2. 官方已经确认的功能面

来源：画世界 Pro 官网首页与官方版本接口。

### 2.1 画笔与笔刷

- `已确认` 超过 150 种内置画笔，覆盖铅笔线条、墨水笔触、炭笔质感、艺术纹理特效画笔。
- `已确认` 有「高级画笔参数设置」，支持定制专属笔刷。
- `已确认` 官网宣传笔刷资源超过 600 支，不定期更新。
- `已确认` 官网宣传模板资源 300+，每周更新。
- `第三方来源` 支持自定义笔刷；高仿生绘画体验与 GPU 加速绘图引擎；压感；无限撤销重做。
- `无法确认` 笔刷文件的具体格式、是否公开、是否兼容 Photoshop ABR；本轮不实现 ABR，只做用户自有 PNG / 灰度笔尖导入。

### 2.2 柳叶笔

- `已确认` 官网把「柳叶笔」列为「便捷工具」：以圈定的方式快速填充颜色或擦除内容。
- `已确认` 3.5.0 修复了「柳叶笔切换不生效」，说明它是有独立模式/状态的工具，不是普通画笔别名。
- `第三方来源` 快速图形工具包括矩形、圆形、直线、柳叶笔。
- 对 Strata 的验证：当前实现 solid / hollow / blur 三模式 + Shift 闭合边吸附，语义与该描述一致；本轮不再改柳叶笔。

### 2.3 图层与编辑

- `已确认` 官网列出「图层组」：高效组织图层，管理作品细节。
- `已确认` 官网列出「内容编辑」：放大缩小、旋转移动、自由编辑内容。
- `第三方来源` 创建剪切蒙版；自动匹配最优图层数；色散、浮雕、油画、高斯模糊等滤镜；自由、扭曲、标准变形工具；画布图像随时可调。
- 对 Strata 的验证：这些能力 Strata 已有大部分（图层组、剪贴蒙版、滤镜、变形、变换），不是本轮重点。

### 2.4 动画

- `已确认` 官网明确支持动画：创作 GIF 或动画短片；**每一帧使用自己的独立图层**；支持多轨道和音频编辑。
- `第三方来源` 洋葱皮功能；导出高清 GIF 与 MP4；时间轴添加帧、帧率、播放预览。
- 对 Strata 的关键启示：画世界 Pro 的帧不是「整张位图快照」语义，而是**每帧一套图层**。Strata 的洋葱皮不能简单存一张 PNG 当帧，至少要能表达「帧 → 图层可见性/内容」。本轮 P3 应做最小帧模型，宁可先支持单图层每帧，也不要做假时间轴。

### 2.5 绘画过程记录与回放

- `第三方来源` 支持绘画过程记录和回放，用来分享回顾创作思路。
- `无法确认` 录制粒度（点 / 笔画 / 时间采样）、文件格式、是否包含笔压与参数变化。
- 对 Strata 的启示：按真实笔画事件记录最稳妥：工具、文档坐标、时间、压力、颜色、大小、流量、修饰键；回放只作用临时层。

- `第三方来源` 没有本次可核对的具体对称/透视机制描述。
- `无法确认` 画世界 Pro 是否有径向 / 曼陀罗对称，是否有灭点吸附；本轮 P1/P2 按「画世界 Pro 可能没有、但专业绘画工作站应该有」来做，不把推测写成已确认。

### 2.7 悬浮调色盘与手势

- `第三方来源` 调色盘支持悬浮拖动，取色更高效。

## 4. 本轮实现边界（按证据写，不脑补）

1. **P1 径向对称**：画世界 Pro 是否有该功能无法确认；按专业绘画工具补齐，不与参考软件绑定。
2. **P2 透视辅助**：同上，做真实导线和端点吸附，不做装饰线。
3. **P3 洋葱皮**：依据官网「每帧独立图层」做最小帧模型；每帧至少可持有自己的像素内容，幽灵帧只读显示。
4. **P4 笔刷导入**：只做用户自有 PNG / 灰度图；ABR 等格式没有确认是公开可读，明确报错即可。
5. **P5 过程回放**：录制真实文档坐标和时间事件；回放先在临时层，用户确认才烙回文档。
