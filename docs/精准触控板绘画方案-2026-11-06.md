# 精准触控板绘画方案（设计稿 · 待拍板）

> 目标：让 Strata 在**精准触控板**（Mac 妙控板 / Windows Precision / Linux 触控板）上画画**不再依赖「按住鼠标拖动」这种难受姿势**。
> 思路：① 悬浮绘制模式（不按键也能落笔）② 触控板手势即落笔 ③ 快捷键瞬间聚焦换色面板并可切回 ④ 自定义快捷键切换常用绘画功能。
> 当前状态：**设计阶段**，以下均可在你点头后分阶段落地。

---

## 一、现状痛点

- 现有绘画 = `pointerdown`（按下）→ 拖动（move）→ `pointerup`（抬起）。触控板上「按住」本身是别扭动作，长时间画画手腕累。
- 触控板只有「移动光标」和「点按」两种输入，没有压感、没有右键拖动；现有方案把「点按+拖动」硬搬到触控板，体验差。
- 换色要手动去右侧面板找，打断绘画心流。
- 快捷键目前写死在 `EditorShell.tsx` 的键盘处理器里，**用户不能改**。

---

## 二、机制一：悬浮绘制模式（Hover-Paint）★核心

> 一句话：**进模式后，手指在触控板上滑动 = 落笔绘画，不用按任何键。**

- **开关**：一个快捷键（草案 `` ` `` 反引号 或 `Ctrl+Enter`）切换悬浮绘制模式。
- **落笔/抬笔的明确规则**（避免「一动就画、停不下来」）：
  - 模式开启后，**光标开始移动** → 自动落笔（pen down）；
  - **移动停止超过 ~200ms** → 自动抬笔（pen up，线条提交）；
  - 再次移动 → 新一笔（与上一笔断开）。
  - 这样「滑一下画一段、停一下换位置再滑」完全贴合触控板直觉，手腕不用按。
- **防误触**：光标离开画布（进入面板/菜单/顶栏）自动抬笔；模式关闭后恢复「点按拖动」传统方式。
- **压感替代**：触控板无压感，可在该模式下把**笔触速度映射成流量**（慢=重、快=轻），作为自然的「伪压感」。
- **与现有管线衔接**：复用 `begin(from) → extend(p) → commit()` 同一套 Stroke 管线（画笔/橡皮都支持），不另起一套。
- **落点精度**：保留「按住 Shift 画直线」「吸附参考线」等现有能力，在悬浮模式下同样生效（用 Shift 修饰即可）。

## 三、机制二：触控板手势 → 落笔 / 视图

| 手势 | 现有 | 本方案新增 / 调整 |
|---|---|---|
| 双指滑动 | 平移画布 | 保留；悬浮绘制模式下可改为「滑动=绘画、平移改用长按拖动或快捷键」 |
| 双指捏合 | 缩放 | 保留（已 `exp(-deltaY*k)` 平滑） |
| 双指旋转 | 视图旋转 | 保留（`rotationDeg` 已接） |
| 轻点（tap） | — | 可选：tap 一下 = 拾色（吸管），避免为吸色专门切工具 |
| 三指 / Force Touch | — | 进阶（Phase C）：Force Touch 压力→流量；三指滑动=切换画笔（OS 级手势需评估冲突） |

> 原则：**平移/缩放/旋转保持系统级手势不变**；把「绘画落笔」从「按键拖动」改为「模式 + 滑动」，互不打架。

---

## 四、机制三：换色面板瞬间聚焦 + 切回

> 你原话：「一个快捷键瞬间聚焦到换色面板，又一个快捷键切回去。」

- **草案**：`Ctrl+Shift+C`（Mac `⌘+Shift+C`）作为**切换键**：
  - 按一下 → 右侧 Dock 瞬间切到「颜色面板」并聚焦到色环/取色器；
  - 再按一下 → 切回切换前的面板（比如刚才的图层面板）。
- 也可做成**两个键**（聚焦 / 还原各一个），但单键切换更省键位；**等你定**。
- 同样可为「画笔面板（`F5`）」「图层面板」「直方图」各配一个聚焦快捷键，组成「绘画专用面板快速通道」。

---

## 五、机制四：自定义快捷键（重映射常用绘画功能）

> 你原话：「自定义快捷键去切换画画很常用的那些功能。」

- **数据模型**：`prefs.keymap: Record<CommandId, Shortcut[]>`（命令 → 一组按键），默认与内置合并；用户改的覆盖内置。
- **UI**：偏好设置里加「键盘快捷键」页（参考 PS 的快捷键编辑器）：列出所有命令、显示当前绑定、点一下「录制新键位」即可重绑；冲突/重复有提示。
- **覆盖的常用绘画命令**（草案，均可改）：
  - 悬浮绘制开关、聚焦换色面板（切换）、画笔↔橡皮切换、笔刷大小 +/-、硬度 +/-、吸管（拾色）、切换前景/背景色、快速蒙版、画笔设置面板、撤销/重做、清除、合并向下。
- **持久化**：存 `strata.prefs`，与现有 `read()` 解析融合。

## 七、分阶段落地计划

- **Phase A（快速见效，低风险）**：悬浮绘制模式开关 + 落笔/抬笔规则 + 聚焦换色面板切换键。改动集中在 `EditorShell` 键盘/指针处理器与新增 `prefs.trackpadPaintMode`。
- **Phase B（自定义快捷键 UI）**：`prefs.keymap` + 偏好设置「键盘快捷键」页 + 键盘处理器读取 keymap。
- **Phase C（高级手势）**：Force Touch 压感映射、tap 拾色、面板快速通道；需真机（尤其 Mac）验证手势不冲突。
