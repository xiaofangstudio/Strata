## 二、留下的东西（有意为之）

### 代码里那些「移植自 PhotoCraft」的注释 —— 不能删

有 24 个文件提到参考项目、14 处写「移植 / 算法对照」。这些**不是残留**，是**许可证要求的来源声明**：

- PhotoCraft 是 **MIT / Apache-2.0 双授权**，MyPaint 是 **LGPL**；
- MIT/Apache 允许移植，但要求在副本中保留版权与许可声明；
- 仓库里的《周末计划-PS功能补齐.md》也明确写着：
  「移植算法合法，但**必须在文件头保留来源声明**」。

删掉这些注释 = 去掉授权归属，是把法律风险换成了"看起来干净"，不划算。

### 自己的产物 —— 保留

- `Strata.exe` / `Strata.lnk` / `release/` / `dist/`：自己的构建产物，不是参考软件。
- `assets/`（品牌资源）、`shaders/`（WebGPU 着色器占位）：自己的目录，只是名字短。

## 五、口径

> **参考副本不进仓库，运行时依赖才进安装包。**

- 参考源码 → 放仓库外（`_回收_*` 或独立目录），只在本机对照时看；
- 移植来的算法 → 代码里保留 `Ported from ... MIT/Apache-2.0` 的头部声明；
- 真正会去调用的（比如将来接 ffmpeg），才考虑进安装包或运行时下载。
