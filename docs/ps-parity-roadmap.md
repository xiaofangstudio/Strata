# Strata 对标 Photoshop 的功能清单与难度评估

这份文档把你列出的七大类、外加钢笔路径与液化，逐条对照当前代码库的真实状态，给出难度星级与判断，供后续开工时翻看。

## 怎么读

每条给四个字段：功能、现状、难度、说明。现状分四档，含义固定。

已完成指主流程与边界都跑通，可以直接用。基本可用指功能齐备但实现方式与最终目标有差距。部分指内核已经存在，只差界面或链路把它接起来。未实现指代码库里还没有对应实现。

难度是五星制，衡量的是从当前状态到目标状态的工作量与不确定度，不是功能本身的高级程度。一颗星通常半天到一天，五颗星是需要新写核心引擎、新接一种文件格式或引入模型。

## 结论先说

这七类里绝大多数不用重头造。图层、混合模式、蒙版、调整图层、图层特效、选区、合成管线、液化这些底层已经落在 `src/core` 与 `src/engine` 里，缺的主要是交互层把它们接出来。真正要从零啃的有四块：Camera Raw、PSD/PSB 读写、相机 RAW 与 HEIC/SVG 解码、钢笔路径配合非破坏变换。这四块都有一份现成的 macOS 参考实现躺在仓库的 `Compositor/` 目录里，可以照着搬算法。

## 钢笔路径

现状未实现，难度四星。

要做的是一条完整的贝塞尔路径：锚点与两个控制柄的存储与编辑、路径的闭合与断开、把路径转成选区、转成蒙版、转成形状、以及在路径上描边或填充。数学是标准的贝塞尔与曲线细分，稳。麻烦的是编辑手感与和其它模块的对接。仓库里 `Compositor` 的 `PSDVector.swift` 提供了矢量路径的表示方式可参考，但没有现成的钢笔工具可搬，要自己写。

## 液化系统

现状基本可用，难度两星。

`engine/liquify.ts` 已经实现了位移场模型，推进、膨胀、收缩、旋转、重建五种模式齐备，界面 `LiquifyDialog` 也在。这套模型比就地改像素更稳，反复涂抹不糊，重建才有意义。剩下的主要是体验打磨，比如笔尖光标的实时反馈、预览分辨率、以及和图层蒙版的配合。`Compositor` 的 `MetalWarp.swift` 与 `SmudgeLiquify.swift` 可以对照补齐细节。

## 建议的动工顺序

短期收益最高的是把已经有内核、只差交互的一批接出来，包括图层面板的拖拽与右键菜单、形状与文字从栅格化改成可编辑对象、参考线与吸附、数值搓值。这一批做完，软件会从「能用」变成「顺手」。

中期啃 Camera Raw 与 PSD 读写，两者体量最大但参考实现最完整，属于照着搬就能成的类型。

钢笔路径与选择主体这类，建议放在有了可编辑矢量层之后再动，因为路径转形状、文字当剪贴蒙版这些都依赖那层结构。
