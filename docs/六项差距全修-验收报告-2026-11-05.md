## 二、复核发现并修复的问题

### 🔴 P0：不存在的权限导致全量构建失败（已修复）

今日实施方在 [capabilities/default.json](file:///d:/20533/deskbox/fangwork/Strata/src-tauri/capabilities/default.json) 追加了
`core:window:allow-clear-effects`，声称「已在 window.d.ts 确认存在」——**JS API 存在 ≠ ACL 权限存在**。
Tauri 2 核心权限表里没有这个权限，构建脚本直接报错退出。

- 根因：`Window.clearEffects()` 的官方实现就是内部调 `set_effects(null)`（见 node_modules 里
  `@tauri-apps/api/window.js` L1220-1224 的实现与 JSDoc「the same one used by setEffects」），
  与 `setEffects` 共用 `core:window:allow-set-effects`，**从来不存在独立的 clear-effects 权限**。
- 修复：从 capabilities 移除 `core:window:allow-clear-effects`（保留 `allow-set-effects`），应用功能不受影响。
- 教训入册：**凡动 `tauri.conf.json` / capabilities，必须跑全量 `npx tauri build`，`cargo check` 抓不到 ACL 错误**。

## 四、遗留边界（实施方自述 + 复核确认，勿对外夸大）

1. **RAW**：CR3 只取内嵌 JPEG 预览（非显影）；JPEG XL 压缩的 DNG 不支持；Clarity/Texture 查表缺失（两滑块空转）；无预览且显影失败时报中文错。
2. **CMS**：软打样/色域警告的**实时预览管线仍是矩阵近似**——`iccSoftProof` API 备好但没接进 useEffect；CMS 无专属单测（计划里要求「往返误差阈值单测」，实际是 `tests/unit/` 下没有 cms.test.ts）。
3. **GPU**：只加速「拼合图像」且限纯像素层文档（有调整层/组/蒙版/样式/剪贴即回退 CPU）；WebGPU 不可用时静默回退。
4. **PSD**：8 种无 PSD 等价物的调整层写成透明占位层并弹名字，效果不进 PSD，需先栅格化。
5. **个性化（同日另一线）**：窗口磨砂走 Tauri Acrylic + `transparent:true`，**真机观感未验证**。
