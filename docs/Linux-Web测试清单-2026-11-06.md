# Strata · Linux / Web 测试清单（2026-11-06）

你正在测的是 **Web 版（浏览器里跑，不是 Tauri 桌面版）**。代码已推到 `origin/main` 并打了 `v2.6.2` 标签，所以你看到的即最新。

> 本清单同时覆盖两件事：
> 1. **预期内差异** —— Web ≠ 桌面，这些不是 bug，不用报。
> 2. **重点测试项** —— 你之前说的「UI 错位、交互顺不顺、面板能不能打开」，逐项过。

## 一、预期内差异（不要当 bug 报）

| 功能 | Web 版表现 | 说明 |
|---|---|---|
| 窗口磨砂（Acrylic / vibrancy） | 顶栏/状态栏会浮出一条「窗口磨砂不可用：非 Tauri 窗口环境」提示，然后降级 | 系统级窗口效果是 Tauri 桌面独占；Web 没有这个概念 |
| 文件 > 打开 / 保存工程 / 导出 PSD | 弹提示「此功能需要桌面版（Strata 桌面应用）」 | 浏览器没有文件系统对话框；现已从「原始报错」改成明确提示 |
| 偏好 > 背景图 | 不生效（降级为无背景图） | `convertFileSrc` 是 Tauri 专属，Web 拿不到本地路径 |
| 双击文件启动 / 拖入文件打开 | 仅桌面版有 | Web 没有单实例转发与系统拖放 |
| 退出 Strata | 直接关浏览器标签即可 | 桌面版走内核退出命令 |

## 二、重点测试项

### A. 启动与首页
- [ ] 启动屏（雪山）正常出现并消失，不卡白屏
- [ ] 开始页：新 logo、最近文件、新建/打开按钮都在
- [ ] 切换亮 / 暗主题（开始页右上角）正常

### B. 编辑器顶栏（`.editor-top`）
- [ ] 亮暗切换、偏好设置、导出、工作区这几个按钮都在、能点
- [ ] 菜单栏（文件/编辑/图像/滤镜/视图/窗口/帮助）逐个展开，子项不溢出、不重叠
- [ ] 菜单项的快捷键提示显示正常（长语言如俄语/德语会不会把菜单撑爆）

### C. 左侧工具栏
- [ ] 每个工具点一下，tooltip / 状态提示准确
- [ ] 工具切换后画布交互正常（画笔、选区、移动、文字等）

### D. 右侧面板
- [ ] 图层面板、颜色面板、直方图、通道、属性、信息 等逐一打开 / 收起
- [ ] 面板里长文本（如俄语标签）**不换行后纵向裁切**（之前踩过这个坑）
- [ ] 面板拖动 / 停靠是否正常

### E. 状态栏（`.statusbar`）
- [ ] 左下尺寸 `宽 × 高` 现在是**可点按钮**：左键 → 图像大小，右键 → 画布大小
- [ ] 缩放比例、文档信息等不溢出

### F. 偏好设置（个性化入口）
- [ ] 左侧第一组就是「个性化」，点进去有：背景磨砂、全局磨砂、窗口磨砂、磨砂颜色、字体、缩放
- [ ] 玻璃四参数（透明度/模糊/饱和/高光）、动效档位、触控板自然滚动、沉浸光效 都能调
- [ ] 改完即时生效，不卡

### G. 快捷键（Web 版最容易踩坑的地方）
- [ ] `Ctrl+W` 关文档 —— **不会**关浏览器标签页（已 `preventDefault`）
- [ ] `Ctrl+S` —— 弹「需桌面版」提示，不会弹出浏览器保存网页
- [ ] `F5` —— **不再整页刷新**（已修）；画笔工具下开/关画笔面板
- [ ] `Ctrl+R` —— 切换标尺，不会刷新页面
- [ ] `Ctrl+Z` / `Ctrl+Shift+Z` 撤销 / 重做
- [ ] `Ctrl+T` 自由变换、`Tab` 沉浸模式、`Ctrl+0` 适配屏幕
- [ ] `P` 开偏好、`Q` 快速蒙版

### H. 字体
- [ ] 中文**不是方框（tofu）** —— 已补 Linux CJK 回退（Noto / Source Han / 文泉驿）
- [ ] 若仍方框：报一下你云电脑装了哪些字体（`fc-list | grep -i cjk`）

### I. 玻璃 / 磨砂观感
- [ ] **全局磨砂**在 Chrome / Chromium 下：卡片应是半透明、能把背后棋盘格模糊出来（不是一块实色、不是丑渐变）
- [ ] 白色高光边、鼠标挪上去按钮有反光
- [ ] **Linux 桌面 deb/AppImage 装好后**重点复测：WebKitGTK 的 `backdrop-filter` 支持有限，玻璃可能不模糊 —— 这是已知风险项，届时专门报

### J. 画布交互
- [ ] 滚轮缩放、触控板捏合、双指旋转、惯性平移顺不顺
- [ ] `Shift+R` 视图转正
- [ ] 缩放后 UI 不溢出、不卡
