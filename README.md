### ✨ 它能做什么

| 场景 | 说明 |
|------|------|
| 🗂️ **图层与蒙版** | 图层组、全套 PS 混合模式、图层蒙版、剪贴蒙版、图层样式 |
| 🎨 **调整与滤镜** | 曲线 / 色阶 / 色相饱和度 / Camera Raw / 模糊 / 杂色 / 光晕 |
| ✂️ **选区与修饰** | 选框 / 套索 / 魔棒 / 内容识别填充 / 修复画笔 / 仿制图章 |
| 🖌️ **绘制** | 画笔 / 橡皮 / 渐变 / 形状 / 文字，**非破坏、随时可改** |
| 📁 **格式** | PNG / JPEG / WebP / HEIC / TIFF / SVG / RAW，**PSD 读写** |
| 🧩 **可被脚本驱动** | 工程是「图层文件夹 + manifest」，**脚本能直接生成与修改** |

> **关于 AI**：本项目**不含任何 AI / 机器学习功能**——不做智能抠图、不做生成式填充、不做自然语言改图。所有算法都是**确定性的、可解释的**图像处理，纯本地运算，绝不上传你的图片。

### 🎯 我们坚持的底线

- ✅ **永久免费**：不开通会员、不做付费墙、不投广告
- ✅ **开源 MIT**：代码全公开，随便看、随便改
- ✅ **本地优先**：图片不出本机，零上传、零遥测
- ✅ **中文原生**：界面 100% 中文，不是外挂汉化包
- ✅ **轻量**：安装包硬性红线 **100MB 以内**（目标 10–20MB），不做几百兆的巨无霸
- ✅ **无 AI**：不引入任何需要模型推理的功能，保持纯粹与可控

### 🚀 怎么装

> 见 [Releases](https://github.com/xiaofangstudio/Strata/releases) 页下载安装包，双击安装即可；安装后桌面生成「Strata」快捷方式。

**系统要求**：Windows 10 / 11（64 位）。依赖系统自带的 **WebView2 运行时**（Win11 及绝大多数 Win10 已预装；未安装时安装包会引导自动装）。

---

### 🛠️ 技术底座（简要）

| 层 | 选型 |
|----|------|
| 桌面外壳 | **Tauri v2**（Rust 内核 + 系统 WebView2，故安装包极小） |
| 界面 | TypeScript + React + Vite |
| 渲染 | **WebGPU 优先**，WebGL2 回退 |
| 图像处理 | **Rust 原生内核**（编解码 / 滤镜 / 合成，多线程加速） |
| 工程格式 | 图层文件夹 + `manifest.json`（明文、可脚本读写、非破坏） |

> 详细的架构与选型说明见 [`docs/立项规划书.md`](docs/立项规划书.md)。
