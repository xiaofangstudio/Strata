### 🎚️ 调整图层：31 种，全部非破坏

调整按用途分三族：**明暗 10 种、色彩 15 种、效果 6 种**。

- **明暗**：亮度/对比度、色阶、曲线、曝光、阈值、色调分离、通道色阶、阴影/高光、均衡、HDR 色调
- **色彩**：色相/饱和度、全功能色相/饱和度、色彩平衡、黑白、黑白（通道权重）、渐变映射、通道混合器、反相、色温、照片滤镜、自然饱和度、可选颜色、颜色查找、匹配颜色、替换颜色
- **效果**：Camera Raw、模糊、动感模糊、锐化、颗粒、添加杂色

技术上分四条路走，但对你来说只有一件事——**调参数不碰像素，随时可改可删**：

1. Canvas2D 自带滤镜：亮度对比度、色相饱和度、去色、反相、模糊；
2. SVG `feComponentTransfer`：色阶、曲线、曝光、阈值、色调分离、渐变映射、色彩平衡；
3. SVG 其它原语：通道混合器（`feColorMatrix`）、锐化（`feConvolveMatrix`）、动感模糊（各向异性 `feGaussianBlur`）、颗粒与杂色（`feTurbulence`）；
4. **逐像素内核**：有 11 种没法用滤镜精确表达，统一走 `engine/adjustPixels` 的 ImageData 进 / ImageData 出——自然饱和度、可选颜色、黑白（通道权重）、全功能色相/饱和度、颜色查找、Camera Raw、均衡、HDR 色调、匹配颜色、替换颜色、阴影/高光。非破坏调整层和「图像 > 调整」的一键烙印共用同一段内核，所见即所得。

两个实打实的优化：

- 调整层不占整幅画布，内部用 **1×1 占位**，24MP 的文档每层大约省 **96MB**；
- 参数全在中性值时直接返回空滤镜串，**跳过整次全画布拷贝**。

### 📁 图层组

组不是「一层套一层」的虚拟节点：组内的子层先合成成一张中间结果，组再把这结果当自己的像素画。于是**组的不透明度、混合模式、蒙版、图层样式全部零成本复用**，渲染管线一行都不用改。

### ✨ 图层样式：6 种

投影、内阴影、外发光、内发光、描边（外 / 内 / 居中）、颜色叠加。渲染顺序对齐 PS，样式可复制 / 粘贴 / 一键清除。

### 🎭 混合模式：27 种

16 种直接映射 Canvas2D 的 `globalCompositeOperation`；另外 11 种（溶解、线性加深、深色、线性减淡、浅色、亮光、线性光、点光、实色混合、减去、划分）Canvas2D 不提供，走 `engine/blend` 逐像素软件合成。**名字、分组、效果全部按 PS 来。**

### 📋 菜单栏 + 右键菜单

- 补全 **10 个顶级菜单**：文件 / 编辑 / 图像 / 图层 / 文字 / 选择 / 滤镜 / 视图 / 窗口 / 帮助，快捷键沿用 PS 习惯；

- 画布、图层、参考线都有自己的**右键菜单**，常用操作不用再跑菜单栏。

### 🖌️ 绘制内核改进

- **对称绘制**：垂直 / 水平 / 双轴镜像，一颗笔尖镜像补落，轨迹完全对称，画对称图形、角色正脸很省事；

>
> 把 Claude Desktop、Cursor 这类支持 MCP 的客户端连上 `mcp/strata-mcp.mjs`，

## ❓ 常见问题

**Q：能打开 PSD 吗？**
暂时不能。当前能打开 PNG / JPG / WebP / TIFF / BMP / GIF；工程存成 `.strata`，导出 PNG。PSD 读写还没做，菜单里也不会假装能做。

**Q：为什么菜单里有些项是灰的？**
因为**真的还没做**。灰掉的项会写明原因，实现之后才会点亮——这是故意跟自己较劲，避免「点了没反应」。

**Q：图片会被上传吗？**
不会。Strata 是本地应用，没有账号系统，也没有任何上报。

**Q：支持 macOS / Linux 吗？**
Tauri 本身跨平台，但 Strata 目前只针对 **Windows 10 / 11 64 位** 开发和验证。

**Q：和 PS 的操作习惯差多少？**
工具快捷键（V / M / L / W / B / E / G / T / C / I / H / Z）、菜单分类、图层面板、历史记录都按 PS 摆。切过来基本不用重新学。
